# @jeclazon/ui

Reusable Jeclazon company-level UI foundations.

This package begins with semantic design tokens. Shared components should be added only when they are genuinely reusable across Jeclazon company surfaces or products.

Product brands may override visual identity while preserving accessibility and engineering conventions where appropriate.

Do not turn this package into a mechanism that forces every Jeclazon product to look identical.
